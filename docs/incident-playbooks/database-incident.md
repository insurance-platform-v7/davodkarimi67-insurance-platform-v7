# Database Incident Playbook

## Incident Type

Database outage.

## Impact

Application cannot access persistent data.

## Response

1. Confirm database availability.
2. Check PostgreSQL service status.
3. Verify connection configuration.
4. Restore database connection.

## Communication

Record:

- Incident start time.
- Recovery time.
- Impacted services.

## Resolution

Validate application database access.

## Post Incident

Document the cause and recovery result.
