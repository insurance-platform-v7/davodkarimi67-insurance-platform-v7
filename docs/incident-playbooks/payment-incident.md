# Payment Incident Playbook

## Incident Type

Payment provider or callback failure.

## Impact

Payment flow interruption.

Affected areas:

- Payment verification
- Policy payment workflow
- Transaction status updates

## Response

1. Verify payment provider status.
2. Check payment callback requests.
3. Validate transaction state.
4. Restore payment processing flow.

## Communication

Record:

- Failed transactions.
- Start time.
- Recovery time.

## Resolution

Verify:

- Payment statuses are consistent.
- Workflow continues correctly.

## Post Incident

Document cause and recovery result.
