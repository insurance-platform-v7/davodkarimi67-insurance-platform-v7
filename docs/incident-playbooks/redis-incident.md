# Redis Incident Playbook

## Incident Type

Redis service failure.

## Impact

Cache and Redis-dependent operations are unavailable.

## Response

1. Confirm Redis availability.
2. Check Redis service status.
3. Restore Redis service.
4. Validate application connectivity.

## Communication

Record:

- Incident start time.
- Affected components.
- Recovery time.

## Resolution

Verify:

- Application connectivity.
- Cache operations.

## Post Incident

Document cause and recovery result.
